## 📌 About

This project is my playground for practicing:

- Creating and switching **branches**
- Making **commits** with clear messages
- **Merging** and **rebasing** branches
- Opening **pull requests** on GitHub
- Building a simple website with HTML, CSS and JavaScript

## ✨ Features

- 🏠 **Home page** with an about section, hobbies list and navigation
- 🎨 **Color changer** button built with JavaScript
- 📝 **To-do list** page: add tasks, click to mark them done, delete them

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/sidd8824/dummy-.git
cd dummy-
```

### 2. Open the website

Double-click `index.html`, or open it from the terminal:

```bash
open index.html
```

No installation or build step needed. It runs directly in the browser.

## 🌿 Git Workflow I Follow

```bash
git switch -c my-feature      # create a new branch
git add .                     # stage changes
git commit -m "Describe it"   # save changes
git push -u origin my-feature # upload the branch
```

Then open a **pull request** on GitHub and merge it into `main`.
